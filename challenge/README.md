# ตาไว! เกมบูธ CS100 POWER UP!

เกมจับผิดภาพของนันและเกมจำสีโลโก้เปิดให้เล่นที่
`/challenge/` บนเว็บโปรเจกต์เดียวกับ Portfolio เปิดเว็บหลักแล้วกด **Host Challenge → เปิดเกมตาไว!**

- **จับผิดภาพ** แตะตำแหน่งที่ต่างกันให้ครบ 5 จุดในแต่ละด่าน
- **จำสีโลโก้** ทายสีจากโลโก้ขาวดำ 8 ข้อ พอตอบแล้วจะเห็นภาพสีเฉลย พร้อมคะแนนและเวลาที่ใช้คิด

เล่นจบให้บันทึกรูปหน้าสรุปผล แล้วกด **นำผลไปกรอกในเว็บหลัก** ปุ่มนี้เติมชื่อเกมและผล
ในฟอร์ม Host ให้ แต่ Host ยังต้องใส่ชื่อเล่น Reflection และลิงก์หลักฐานก่อนกดสร้าง Item JSON
การ Import, Save และ Export ทำในหน้าเว็บหลัก

## ลองบนเครื่องตัวเอง

กลับไปที่โฟลเดอร์หลักของโปรเจกต์ รัน `node server.js` แล้วเปิด
[http://127.0.0.1:3000/challenge/](http://127.0.0.1:3000/challenge/)
ลองเล่นให้จบทั้งสองแบบเพื่อเช็กว่าปุ่มส่งผลกลับไปตรงเกม

หน้าเกมใช้ `index.html`, `game.js`, `scene.js` และ `style.css` ในโฟลเดอร์นี้
ฟอนต์ไทยมาจากชุดเกมของนัน ดูสัญญาอนุญาตได้ใน [fonts/LICENSE.txt](fonts/LICENSE.txt)
